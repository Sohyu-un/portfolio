# Portfolio Website

This is a portfolio website project that showcases design and development skills. The project is structured to implement design tokens and components as specified in the provided Figma design.

## Project Structure

```
portfolio-website
├── src
│   ├── index.html          # Main HTML document for the website
│   ├── assets
│   │   ├── css
│   │   │   └── styles.css  # Main styles implementing design tokens
│   │   ├── js
│   │   │   └── main.js     # JavaScript for interactivity
│   │   └── images          # Directory for image assets
│   └── components
│       └── tokens.css      # Design tokens for reusable styles
├── README.md               # Project documentation
└── package.json            # npm configuration file
```

## Setup Instructions

1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Install the necessary dependencies using npm:
   ```
   npm install
   ```
4. Open `src/index.html` in your web browser to view the website.

## Features

- Responsive design that adapts to various screen sizes.
- Implementation of design tokens for consistent styling.
- Interactive elements powered by JavaScript.
